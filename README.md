# Heating-Assistance-Project

Heating Assistance Project

This dashboard provides a clear overview of the Nova Scotia Heating Assistance Program (HARP), with data collected between 2015 and 2024. Through identifying trends and patterns, such as the higher rate of homeowner applicants, the data is prepared to be used for betterment of HARP. For example, the rejection rate for applications has increased notably since 2020, which may indicate need for expansion. Additionally, analysis of applicant characteristics and service use can be used in the future for better support and ease-of-use for the average applicant.

Goals for this dashboard include:
- Tracking performance
- Recognizing trends/patterns
- Understanding applicants
- Analyzing service use


Data Source:
  Nova Scotia's Government Open Data Portal
  Heating Assistance Rebate Program
  https://data.novascotia.ca/Government-Administration/Heating-Assistance-Rebate-Program/8s6t-aehm/about_data
